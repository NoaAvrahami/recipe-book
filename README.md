

# 🍳 Recipe Book App

## אודות הפרויקט
אפליקציית רשת לחיפוש, צפייה ושמירת מתכונים. האפליקציה שואבת נתונים בזמן אמת משרת חיצוני ומאפשרת למשתמשים לנהל רשימת מתכונים מועדפים אישית. 
הפרויקט פותח כחלק ממטלת קורס ומשלב עקרונות מתקדמים של פיתוח צד-לקוח.

## מה האפליקציה עושה?
* **חיפוש חכם:** מציאת מתכונים לפי שם מתוך מאגר נתונים חיצוני.
* **עמוד פרטי מתכון:** צפייה במרכיבים, כמויות והוראות הכנה מלאות.
* **ניהול מועדפים:** שמירת מתכונים אהובים. המידע נשמר מקומית בדפדפן, כך שהמתכונים נשמרים גם לאחר רענון או סגירת הדף.
* **מתכון אקראי:** הגרלת מתכון אקראי וחדש מהשרת בלחיצת כפתור.
* **ניווט חלק:** מעבר מהיר בין עמודי האפליקציה ללא טעינה מחדש של הדף.

## מה עשינו (טכנולוגיות ועמידה בדרישות)
* **תשתית הפרויקט:** בניית הבסיס באמצעות הכלים React ו-Vite.
* **המרה לטיפוסים:** מעבר מלא של הפרויקט ל-TypeScript, כולל הגדרת ממשקים קפדניים ללא שום שימוש בטיפוסי any.
* **הוספת ניתוב:** שילוב של React Router ופיצול האפליקציה לעמודים שונים (בית, פרטים, מועדפים, אקראי).
* **ארכיטקטורת רכיבים:** פיצול קוד התצוגה מקובץ אחד מרכזי למבנה מודולרי, הכולל תיקיות נפרדות עבור הרכיבים והעמודים.
* **בדיקות אוטומטיות:** כתיבת 8 בדיקות יחידה לוגיות שעוברות בהצלחה בעזרת Vitest (למשל: וידוא תקינות סינון המתכונים ולוגיקת הוספת המועדפים).

## איך להריץ את הפרויקט מקומית?
1. התקנת התלויות והספריות: הריצו בטרמינל את הפקודה `npm install`
2. הפעלת שרת הפיתוח: הריצו בטרמינל את הפקודה `npm run dev`
3. הפעלת בדיקות היחידה: הריצו בטרמינל את הפקודה `npm run test:ui`
